# 快递短信助手

一款在 Mac 上整理快递短信的原生应用。从已经转发到 Mac「信息」里的快递短信中提取配送状态、运单号、取件码和驿站信息，收货后可以归档。

**[下载安装包](https://github.com/lsk-000478/parcel-sms-assistant/releases/latest)** · **[下载与使用页面](https://lsk-000478.github.io/parcel-sms-assistant/)**

## 目前可以做什么

- 按进行中、待取件、配送到家、寄出／运输、已收货归档整理通知。
- 提取短信中明确给出的取件码、运单号、驿站和预计送达文字；没有提供的信息保留未知。
- 同一个完整运单号的通知合并成时间线。只有尾号的通知分别保存，避免误合并。
- 根据明确的平台签名或购买语境识别购物平台，显示彩色文字标识。快递公司名称不能证明购买平台。
- 根据签收短信自动归档，或手动点击「标记已收货并归档」。支持撤销手动标记，归档在重启后保留。
- 开始读取成功后，每 60 秒刷新一次；应用需要保持运行。

## 安装和首次使用

发布包适用于 **Apple Silicon Mac（M 系列），macOS 14 或更高版本**。目前在开发者的 macOS 26 设备上实测，未在所有系统版本和机型上验证。

1. 从 Releases 下载 ZIP，解压后将「快递短信助手.app」拖到「应用程序」。
2. 这是一份临时签名、未经 Apple 公证的个人项目。首次打开可能被系统拦截。核对来源后，按系统提示在「系统设置 → 隐私与安全性」中选择「仍要打开」。
3. iPhone 和 Mac 的「信息」需使用同一个 Apple 账户。先确保 iPhone 新收到的普通短信能自动出现在 Mac 的「信息」中。可以使用系统的短信转发功能，项目本身不连接 iPhone，也不要求将短信发送到 AI 服务。
4. 在「系统设置 → 隐私与安全性 → 完全磁盘访问权限」中，添加并允许「快递短信助手」，然后退出并重新打开它。此权限范围较广，请只对你信任的应用授权。
5. 点击应用中的开始读取／刷新按钮。先检查真实短信，再核对工具识别的内容。

详细说明见 [使用说明.txt](使用说明.txt)。

## 使用边界

- 读取本机信息数据库中最近 90 天、最多 5000 条收到的 SMS／RCS，排除 iMessage，仅保留识别到的快递通知。
- 没有购物平台的登录或订单接口，无法读取全部订单，也无法感知用户在其他应用点击「确认收货」。没有签收短信时，请在本工具内手动标记。
- 商品名称和图片通常不在短信中，当前不会从购物平台补充。预计送达和即将上门仅依据短信原文。
- 已完成普通短信转发到 Mac、配送状态识别、手动归档、重启保留与撤销的实际验证；其他规则有样例测试，尚无大规模准确率评测。

## 数据与隐私

工具以只读方式访问 `~/Library/Messages/chat.db`，不修改短信、发送消息或改变已读状态。识别与归档都在本机执行，源码没有网络请求。手机到 Mac 的短信转发使用 Apple 系统功能和网络。

收货归档保存在 `~/Library/Application Support/ParcelSMSInbox/receipts.json`，包含相关原短信、运单号、发件人及时间。目录权限为 0700，文件权限为 0600；它不是额外加密的数据库。目前没有自动清理和删除归档的界面。GitHub 仓库和安装包不包含使用者的短信或归档数据。

## 本地开发

需要 macOS 和 Xcode Command Line Tools，源码使用系统 SwiftUI、AppKit、Foundation 和 SQLite，无第三方依赖。

```bash
bash test.command
bash build.command
```

默认构建 Apple Silicon、最低 macOS 14 的 `.app`。可用 `TARGET`、`BUILD_DIR` 和 `APP_OUTPUT_DIR` 指定编译目标与输出目录。构建产物采用临时签名；替换已安装应用后，macOS 可能要求重新授予读取权限。

```bash
APP_OUTPUT_DIR="$PWD/.build/release" bash build.command
```

## 目录

- `Sources/`：界面、短信读取、正文解码、解析与归档。
- `Resources/Info.plist`：应用元数据。
- `Tests/`：解析、平台识别、归档及正文格式兼容测试。
- `docs/`：GitHub Pages 下载和使用页面，不处理短信。
- `.github/workflows/check.yml`：自动测试并构建应用。
